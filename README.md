# AG University Services

Bilingual Arabic/English university services website, especially for Homs University.

## Publishing
In GitHub Settings → Pages, select Deploy from a branch, main, /(root). Set the custom domain to services.aoussgabash.com. At the DNS provider, add CNAME services → aoussgabash.github.io (remove conflicting records for services). Enable HTTPS when GitHub makes the option available.

## Content
Edit index.html to add verified announcements and services. Keep Arabic and English text aligned. Announcements should include the source, publication date and applicable deadline. Do not mark services available before activation.
